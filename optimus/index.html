Research catalog · November 2026

Optimus

An enterprise AI task is a program — business logic and data with model calls at a few points — and the interesting question is how to optimise and certify that program, not any one model. This catalog organises the companies, papers, products, articles and benchmarks working on that question: prompt and program optimisers, workflow search and compilation, semantic-operator optimisers from the database world, harness engineering, and the commercial attempts at “describe the task, we optimise it”.

What’s new · 2026-11-17

Sweep since September: eval-gated optimisation goes mainstream

Microsoft, AWS and Salesforce now all ship the same loop inside their agent platforms: mine production traces, propose changes to prompts, tools or models, test them, and promote only what passes. AWS validates proposed changes with A/B tests before promoting them; Microsoft adds human approval, and Salesforce generates regression tests.
