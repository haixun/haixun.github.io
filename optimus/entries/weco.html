People Zhengyao Jiang, Yuxiang Wu

Summary

Research and product lab whose agents optimise source code against the user's evaluation script: kernels, ML pipelines, hyperparameters and prompts, via the open-source weco CLI and a hosted platform. Built AIDE (tree search over ML-engineering solutions) and AIDE², where an outer loop rewrites the research agent.

Our take

The only genuine cross-approach searcher found, because it searches code rather than a menu of approaches; but it needs the metric handed to it and has no compliance story. Closest in spirit to the search route of the thesis.
