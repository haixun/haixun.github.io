Summary

Free desktop workbench plus MIT-licensed Python library that ties evals, prompt and harness tuning, fine-tuning (via Fireworks, Together, Vertex and others), RAG, sub-agents and synthetic data to one task and dataset. Its Harness Tuner searches over models, providers, prompts, skills and tool code against the user's evals.

Our take

The closest thing in market to the thesis, roughly 70% there and free, which caps what a pure optimiser can charge. Candidates must still be built by a human and there is no compliance story; its own line ('Stop guessing. Start measuring.') concedes measurement comes first.
