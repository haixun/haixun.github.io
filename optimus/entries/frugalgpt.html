FrugalGPT: How to Use Large Language Models While Reducing Cost and Improving Performance

author-reported

physical-plansearchmetricgeneralcascades-routingcost-quality

arxiv.org/abs/2305.05176

People Lingjiao Chen, Matei Zaharia, James Zou

Summary

Surveys LLM API pricing and three cost strategies (prompt adaptation, LLM approximation, LLM cascade), and proposes FrugalGPT, a learned cascade that decides which models to query for each input and when a cheaper answer is good enough.

Our take

The reference cascade paper; it works per query and per call, so it is one physical operator in our plan space rather than a program optimiser.

Key numbers

  • Matches GPT-4 with up to 98% cost reduction, or +4% accuracy at equal cost (author-reported)
