Summary

A source-code audit of eleven production coding harnesses (Claude Code, Codex CLI, Gemini CLI, Mistral Vibe, OpenHands, Aider, Mini-SWE-Agent, Hermes, Pi, OpenCode, OpenClaw) plus Databricks' Omnigent meta-harness, across roughly four million lines, re-audited a quarter later. It maps seven canonical subsystems, 13 observations and 29 design patterns, and describes rather than ranks.

Our take

The only empirical description of what shipped harnesses contain: no production runtime imports an agent framework, and none uses vector RAG for code. That argues against emitting to the framework layer, though the authors tie the reasons to code specifically.

Key numbers

  • 0 of 11 production harnesses import a general-purpose agent framework (author-reported)
  • Skills lead MCP in adoption, 9/11 vs 8/11; ACP ships in 6 of 11 (author-reported)
  • Three of twelve observations needed substantive revision within one quarter (author-reported)
  • Codex workspace 621K → ~1.12M lines of Rust in one quarter (author-reported)
