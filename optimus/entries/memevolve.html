MemEvolve: Meta-Evolution of Agent Memory Systems

arxiv.org/abs/2512.18746

People Guibin Zhang, Haotian Ren, Chong Zhan, Zhenhong Zhou, Junhao Wang, He Zhu, Wangchunshu Zhou, Shuicheng Yan

Summary

Jointly evolves an agent's experiential knowledge and its memory architecture, so the system refines how it learns as well as what it stores. Ships EvolveLab, a codebase that reduces twelve memory systems to a modular encode/store/retrieve/manage design space.

Our take

Memory architecture as a searchable component is one rung of the ladder; useful as a design-space reference, less so as evidence about acceptance.

Key numbers

  • Up to 17.06% improvement on SmolAgent and Flash-Searcher (author-reported)
  • Twelve memory systems distilled into one modular design space (author-reported)
