Summary

A declarative system for LLM document-processing pipelines whose optimiser targets accuracy rather than cost: an agent applies logical rewrite directives that decompose the data or the task, synthesises task-specific validation prompts to evaluate candidate plans, and searches for promising plans. Open source at docetl.org.

Our take

The closest academic work to rewriting the logical program itself, with an agent-written evaluator; that evaluator is an LLM judge inside the loop, which is exactly the gate we want kept outside it.

Key numbers

  • Plans 25-80% more accurate than well-engineered baselines on four document tasks (author-reported)
  • Over 1.7k GitHub stars as of March 2025 (author-reported)
