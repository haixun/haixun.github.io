AlphaEvolve: A coding agent for scientific and algorithmic discovery

author-reported

algorithmsearchmetricproofsciencegeneralself-improvement

arxiv.org/abs/2506.13131

People Alexander Novikov, Ngân Vũ, Marvin Eisenberger, Emilien Dupont, Po-Sen Huang, Adam Zsolt Wagner

Summary

An evolutionary coding agent that orchestrates LLMs to improve an algorithm by editing code, with feedback from one or more automated evaluators. Applied to data-centre scheduling, hardware circuit simplification, LLM training kernels and open mathematical problems.

Our take

Shows evolutionary code search works when a human-defined evaluator is cheap and exact; enterprise workflows rarely have that, which is the whole problem. Program evolution, not workflow optimisation.

Key numbers

  • 4×4 complex-valued matrix multiplication with 48 scalar multiplications, the first improvement over Strassen in this setting in 56 years (author-reported)
