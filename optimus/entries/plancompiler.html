PlanCompiler: A Deterministic Compilation Architecture for Structured Multi-Step LLM Pipelines

author-reported

arxiv.org/abs/2604.13092

People Pranav Harikumar

Summary

Separates planning from execution for structured LLM pipelines: the model plans over a typed node registry, the graph is statically validated and topologically compiled, and a prevalidated graph with explicit parameter and type constraints runs instead of autoregressive chaining. Evaluated on 300 tasks across six benchmark sets covering workflow depth, SQL round-trip persistence and schema stress tests.

Our take

A small single-author result, but a clean instance of 'the plan is checked before it runs'. It shows the reliability and cost upside of compiling against a registry; it does nothing about quality of semantic steps.

Key numbers

  • 100% accuracy on depth Sets A and B, 88% on Set C, 96% on Set D (author-reported)
  • Schema-trap tasks: 44/50 against 20/50 for GPT-4.1 and 26/50 for Claude (author-reported)
  • Total inference cost $0.356 across the suite against $2.140 for GPT-4.1 and $18.391 for Claude code generation (author-reported)
