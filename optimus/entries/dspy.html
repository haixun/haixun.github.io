Summary

A programming model that expresses LM pipelines as graphs of declarative modules (signatures) and a compiler that optimises any such pipeline against a user metric by bootstrapping demonstrations, writing instructions or fine-tuning. The framework has since become the reference implementation for prompt and program optimisers (MIPROv2, GEPA, BetterTogether).

Our take

The canonical 'logical program, optimised physical realisation' framing for LM pipelines and the de facto substrate others target; but the program is Python glue, the metric is the only spec, and nothing certifies the result. The adoption-friction thread on Hacker News is the cautionary data point.

Key numbers

  • Compiled pipelines beat standard few-shot prompting by over 25% (GPT-3.5) and 65% (llama2-13b-chat) (author-reported)
  • Beat pipelines with expert-created demonstrations by 5-46% and 16-40% respectively (author-reported)
