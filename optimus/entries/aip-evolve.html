Summary

Foundry feature that coordinates 'fleets of AI FDE agents' to improve an AI system: the user sets a target resource, a goal (model migration, cost or latency reduction, eval score, custom), a validation strategy and limits. Agents create test cases, compare candidates against the baseline and return a proposal with validation results, a confidence assessment and limitations for human acceptance via Global Branching.

Our take

The closest commercial match to our problem, because the business logic lives in Palantir's Ontology and the optimiser can see it. Locked to Palantir, validated on a handful of generated test cases rather than certified.

Key numbers

  • Docs example: 10 test cases, GPT-4o swapped for GPT-5.4 Mini, average compute cost cut 65% (204.6 to 72.4 compute-seconds per call) with all tests passing (vendor-reported)
