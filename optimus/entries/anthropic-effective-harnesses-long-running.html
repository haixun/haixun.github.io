Anthropic: Effective harnesses for long-running agents

People Justin Young

Summary

Describes a two-part harness for agents that work across many context windows: an initializer agent sets up the environment and a coding agent makes incremental progress, leaving artifacts (feature list, progress file, git commits) for the next session, because compaction alone is not enough.

Our take

Concrete evidence that harness structure, not model capability, decides long-horizon reliability, and that it is hand-tuned per model generation.
