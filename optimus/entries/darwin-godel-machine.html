Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents

arxiv.org/abs/2505.22954
code: github.com/jennyzzt/dgm

People Jenny Zhang, Shengran Hu, Cong Lu, Robert Lange, Jeff Clune

Summary

A coding agent that iteratively modifies its own code, validating each change empirically on coding benchmarks, and keeps an open-ended archive of agents from which new variants are sampled. Discovered improvements include better edit tools, long-context management and peer review.

Our take

The reference point for open-ended self-modifying agents, and an argument that harness changes (edit tools, context handling) carry most of the gain. Acceptance is benchmark score on the same tasks it optimises.
