People Harrison Chase

Summary

Maker of the LangChain and LangGraph open-source agent frameworks and LangSmith, a tracing, evaluation and deployment platform; positions itself as 'the platform for agent engineering'.

Our take

The default agent-framework vendor; its LangSmith eval and tracing loop is what customers may already run. An audit of eleven production harnesses found none importing an agent framework, so we should emit plain code rather than target LangGraph.
