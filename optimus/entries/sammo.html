Symbolic Prompt Program Search: A Structure-Aware Approach to Efficient Compile-Time Prompt Optimization (SAMMO)

People Tobias Schnabel, Jennifer Neville

Summary

SAMMO represents prompt programs symbolically so that structural transformations (sections, examples, formats) can be searched at compile time, generalising earlier prompt optimisers. Evaluated on instruction tuning, RAG pipeline tuning and prompt compression across several LLMs.

Our take

Treating the prompt as a structured program with rewrite rules is the right abstraction for a compiler; small footprint and rarely seen in production.
