Summary

Builds 'Droids', autonomous coding agents for enterprise software engineering that work across the IDE, terminal, CI and ticketing. Its own harness engineering (context management, tool design) is a frequent public reference for agent-harness practice.

Our take

Evidence that a well-engineered harness on rented models can be a large business; also the canonical case of a harness whose value is tied to one task domain (code) and which must be re-tuned each model generation.
