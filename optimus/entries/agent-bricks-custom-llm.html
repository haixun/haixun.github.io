Summary

Agent Bricks task type, launched in beta in June 2025, that took a task description plus labelled data, unlabelled data or a few examples (at least 100 inputs), generated evaluation guidelines and pass/fail judges, compared prompting and fine-tuning strategies over a few hours and returned a cost-optimised candidate. Between February and April 2026 the docs marked it 'a legacy offering' and pointed users to SQL AI Functions such as ai_query.

Our take

The most-cited 'describe the task, we optimise it' product, retired as a wizard while the capability moved into SQL functions and a code-first agent platform. It optimised one task, not a program, and never ran in Enhanced Security and Compliance workspaces, where regulated data lives.
