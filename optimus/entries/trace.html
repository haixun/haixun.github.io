Summary

Frames workflow optimisation as Optimization with Trace Oracle (OPTO): an optimiser receives the execution trace plus feedback on the output and updates heterogeneous parameters such as prompts and code. It ships a Python library, Trace, that records traces with PyTorch-like syntax, and an LLM optimiser, OptoPrime, shown on numerical optimisation, prompt tuning, hyperparameter tuning, robot control and code debugging.

Our take

The cleanest formalisation of 'execution traces are the gradient', and it optimises code as well as prompts; like TextGrad it has feedback but no quality estimation or certification.
