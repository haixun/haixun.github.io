Deep Research is the New Analytics System: Towards Building the Runtime for AI-Driven Analytics

Summary

Argues that AI-driven analytics needs a runtime combining optimised semantic-operator execution with the dynamic planning of Deep Research agents. The prototype, built on Palimpzest, lets agents write and run optimised semantic-operator programs, adding compute and search logical operators and a Context abstraction.

Our take

The Palimpzest group moving from fixed queries to agent-written plans, i.e. an optimiser under an agent; still a vision paper evaluated on two queries.

Key numbers

  • Up to 1.95x better F1 than a standard open Deep Research agent (author-reported)
  • Up to 76.8% cost and 72.7% runtime savings against an agent given semantic operators as tools (author-reported)
