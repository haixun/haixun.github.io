People Alex Conway, Debadeepta Dey, Stefan Hackmann, Matthew Hausknecht, Michael Schmidt, Mark Steadman, Nick Volynets

Summary

Introduces syftr, an open-source framework using multi-objective Bayesian optimisation with a Pareto pruner to search RAG and agentic workflow configurations for accuracy, cost and latency trade-offs. Describes the search space and results on CRAG.

Our take

Shows the economics of configuration search: about $500 per use case buys an order-of-magnitude cheaper workflow at small accuracy loss.

Key numbers

  • Search space over 10^23 configurations; about 500 workflows evaluated per run; about $500 per use case (vendor-reported)
  • Knee-point workflow about 10x cheaper for a few accuracy points (vendor-reported)
