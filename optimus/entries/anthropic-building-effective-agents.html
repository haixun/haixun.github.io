Summary

Distinguishes workflows (LLMs and tools on predefined code paths) from agents (LLMs directing their own process), catalogues composable patterns (prompt chaining, routing, parallelisation, orchestrator-workers, evaluator-optimizer, autonomous agents) and advises starting with direct API calls rather than frameworks.

Our take

The vocabulary most enterprise teams use for their programs, and an early lab endorsement of plain code over frameworks, which supports emitting plain code from the optimiser.
