JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution

author-reported

harness-codecompileweight-updatemetricgeneralharness-engineeringself-improvement

arxiv.org/abs/2608.25593
code: github.com/bingreeky/JIT

People Guibin Zhang, Leo Lu, Fangzhou Xie, Kang Zhu, Junhao Wang, Zhifei Xie, Zhaochen Yu

Summary

A model trained to synthesise task-adaptive harnesses on the fly for off-the-shelf agentic LLMs, with the harness formalised as a fixed four-module protocol. It customises, repairs and self-evolves harnesses using an archive of prior configurations.

Our take

Harness generation as a trained model rather than a search loop: a cheaper physical-plan generator, if the claims hold. Comparisons to OpenCode and Claude Code are the authors' own.

Key numbers

  • DeepSeek-V4-Flash with JIT-Agent surpasses GPT-5.6 on DeepSearchQA (+9.1) and OdysseyBench (+4.3) (author-reported)
  • GLM-5.2 gains up to +20.2 points (author-reported)
