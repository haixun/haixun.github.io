Sweep since September: eval-gated optimisation goes mainstream

Microsoft, AWS and Salesforce now all ship the same loop inside their agent platforms: mine production traces, propose changes to prompts, tools or models, test them, and promote only what passes. AWS validates proposed changes with A/B tests before promoting them; Microsoft adds human approval, and Salesforce generates regression tests.

A new cohort of startups sells the same loop independently: Remanence ($30M from EQT Ventures and FirstMark, announced today) retrains open-weight models on a customer's own traces and leaves the weights with the customer; Orchestra switches to a cheaper model or a trained specialist only when it beats a held-out evaluation; Crux Labs, RELAI, Plurai, Autoheal, Raindrop and Papaya cover judging, simulation and repair.

Research on self-evolving agent harnesses has exploded, with about 70 papers since September. The ones added here are the minority that ask whether the gains are real: selection noise and acceptance rules in self-improvement loops, attribution of harness gains, risk-certified prompt optimisation, and the cost of the loop itself. A database-style thread continues alongside: cost-accuracy optimisation for semantic queries, an algebra for agent workflows, and compilers for agent pipelines.
