Towards Security-Auditable LLM Agents: A Unified Graph Representation

author-reported

factsagenticdecision-recordgeneralattestationsecuritykg-construction

arxiv.org/abs/2605.06812

Summary

Proposes a unified graph representation of agent execution so that security properties can be audited over it.

Our take

Notable because the auditable artefact it proposes is a graph. If agent accountability converges on graph representations, the skills in this catalog's graph tier transfer directly to the assurance tier.
